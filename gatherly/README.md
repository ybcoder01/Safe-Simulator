# Gatherly

Find your people by doing something together.

Gatherly is a mobile-first prototype for small real-world plans in Dubai. The unit is an activity, and each activity has a room for before, during, and after.

## Run

```bash
cd gatherly
npm install
npm test
npm run dev
```

Open http://localhost:3210. Continue as Maya Chen, or enter any email and the demo code `246810`.

Auth, reminders, moderation, and realtime are simulated on this device. The Postgres shape lives in `db/schema.sql`. Product decisions live in `PRODUCT.md`.

Reset the seeded city from Settings.
